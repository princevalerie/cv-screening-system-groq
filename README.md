# CV Screening System using Groq and Streamlit

## Overview
This repository contains the CV Screening System developed using Groq and Streamlit. It aims to automate the screening of resumes/CVs using advanced natural language processing techniques and user-friendly interfaces.

## Features
- **Resume Upload**: Users can upload their CVs in various formats.
- **Automated Screening**: The system utilizes Groq for NLP tasks, analyzing and scoring resumes based on predefined criteria.
- **User Dashboard**: An intuitive dashboard built with Streamlit for managing uploaded CVs and viewing results.
- **Deployment Integration**: The application is accessible via a web interface for seamless user experience.

## Technologies Used
- **Groq**: For high-performance querying and data processing of resumes.
- **Streamlit**: For creating interactive web applications.

## Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/princevalerie/cv-screening-system-groq.git
   ```
2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the application:
   ```bash
   streamlit run app.py
   ```

## Deployment
The live application can be found at [CV Screening System](https://cv-screening-system-groq.streamlit.app/).
